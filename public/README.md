# public/

Archivos servidos tal cual desde la raíz del sitio.

Pon aquí el logo del país y referencia la ruta desde `config/brand.ts`:

    public/colombia.png   →   logo: "/colombia.png"

Recomendado: PNG cuadrado de 96×96 o más (se recorta a un cuadrado redondeado de 30 px en
la cabecera). Si `logo` es `null`, la cabecera muestra el emoji configurado y, si tampoco
hay, el código del país.
